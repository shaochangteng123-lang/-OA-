# 开发生产源码彻底同源修复

## 问题

主工作区和生产源码都基于同一个旧提交，但长期保留在两个未提交工作目录中继续开发。2026-09-11 至 2026-09-14 上线的非主营支出、三方合同、目标金额、第二批历史合同、辅助材料、采购识别和合同下载源码只完整保存在生产工作目录；主工作区则独有社保回单版本 6、董事长福利双分类、住房发票租期分摊、一般账户出账指标及部分资产财务优化。

后续生产镜像从生产工作目录完整构建时，覆盖了主工作区独有的社保修复；开发容器重新挂载主工作区后，又因缺少生产已有的非主营支出分类而无法通过开发数据库约束校验。

## 归并结果

- 已验证生产工作目录重新编译后的 217 个服务端文件和 391 个前端资源与当前生产镜像逐一完全一致，作为生产权威源码基线。
- 以共同旧提交为基线执行三方归并，将生产侧合同、月度财务和历史工具源码，与主工作区社保、报销、福利、租期分摊、出账和资产财务修改合并。
- 主工作区共机械同步 303 个已修改或新增源码文件，没有删除现有源码文件；归并前两侧完整源码快照均已保存。
- 合同域保留非主营支出、三方主体、目标金额、采购识别第二十一版、辅助材料与合同下载，同时恢复公证费资金方式自动补齐及资产先付款后补发票。
- 月度财务同时保留福利账户一／二动态分类、住房发票按租期分摊、五项出账指标和三处报销月份统一，并保留生产侧人民币旧回单核验、项目回单预览及历史导入闭环。
- 人力成本恢复社保识别版本 6、遮挡账号严格校验、补打回单错行金额处理、电子回单号事务查重及多文件追加。
- 数据库迁移提前升级非主营支出分类约束，避免既有数据在后续归一更新前被旧白名单拒绝。
- 生产启动新增人力成本关键接线检查；社保版本低于 6、遮挡账号兼容或查重服务缺失时拒绝进入健康状态。
