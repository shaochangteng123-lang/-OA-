# 开票申请材料独立归档生产发布

发布日期：2026-09-16

## 发布结果

- 合同详情“合同附件”新增管理员专属“开票申请材料”分组，按开票申请编号展示申请状态、申请人、金额、时间和附件数量。
- 申请上传材料、系统生成三联单及已交付盖章材料均进入该分组；正式发票、回单、用印申请单和普通合同文件保持原分组。
- 已明确关联开票申请的盖章后三联单或其他材料不再出现在“合同→主合同”，页签总数按实际展示文件计算且不重复。
- 草稿和驳回申请不进入合同归档；只有交付完成的盖章材料显示为“盖章后三联单”或“盖章后申请材料”。
- 普通员工、总经理和 BOSS（经营管理）不通过合同详情读取该组材料；管理员预览与下载同时校验合同归属、安全路径、真实格式和 `SHA-256（安全散列算法）`摘要。
- 普通员工合同附件下载候选排除开票申请材料，既有已生成下载申请快照不改写。

## 数据迁移

- `contract_files`（合同文件表）新增可空 `invoice_application_id`（开票申请外键）。
- 历史回填只处理交付审计中同一文件唯一指向一笔申请、合同一致且类型为三联单或其他材料的记录；存在多申请歧义或无法匹配的文件保持原分类。
- 生产共核对 1 条交付审计，缺文件编号、文件不存在、跨合同、格式错误、类型错误及重复申请映射均为 0；最终安全关联 1 个当前文件。
- 生产仍有 67 个未关联的历史三联单或其他文件，全部保持原合同附件分类，未按文件类型猜测归属。
- 合同级当前审批材料唯一索引移除三联单限制，新增每笔开票申请最多一份当前盖章材料索引；同一合同多次开票可分别保留材料。
- 未搬迁、复制或改名任何物理文件。
