`rollback.yml` 固定指向旧生产镜像。若应用层需要回滚，只重建 `yulilog` 应用服务并重载 Nginx（反向代理）：

```bash
docker compose -f backup/team-worklog-release-20260921.v1/rollback.yml up -d --no-build --no-deps --force-recreate --wait --wait-timeout 180 yulilog
bash scripts/reload-production-nginx.sh
```

补齐的调休日期和补全后的周报属于正确性修复，应用回滚时默认保留。切换后的正常用户操作已经发生，禁止直接用切换前全库备份覆盖生产；完整备份仅用于隔离恢复核验或经明确授权的灾难恢复。
