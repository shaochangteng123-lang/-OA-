# 一般账户出账指标与来源连通验收

## 状态

已完成开发、正式数据副本接口与浏览器验收，并于2026-09-08 10:14正式上线；最终上线结果见《一般账户出账指标生产发布-2026-09-08》。以下保留开发验证过程，未修改原始报销、付款日期、银行流水、账户金额或月报快照。

## 修改范围

1. 一般账户跨行手续费仅取有效`general_bank_fee`（跨行手续费）；不再混入杂项、基础／大额报销、商务手续费，银行接管后无效手工记录不重复计入。
2. 行政支出为基础报销＋大额报销，不依赖报销用途，冻结来源无当前分类也按明确报销类型计算。
3. “查看指标”及多指标列表均移除业务支出、一般账户总支出、一般账户支出（已录入部分）。当前五项为行政、薪资、一般账户跨行手续费、实际税费、资产类合同支出；总额保留给原账户摘要和饼图中心核对，其他杂项独立保留在来源明细，不影响原账。
4. 来源完整性按单项判断，避免一个无关来源或整体差额将全部折线变成未知；总额差额仍提示，不借其他费用拼手续费，不造零。过滤后的序列保持稳定引用，不清除用户刚选中的点位。
