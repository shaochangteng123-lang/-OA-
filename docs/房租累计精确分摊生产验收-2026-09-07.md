# 房租累计精确分摊生产验收

## 已实现并上线

保留金额两位小数及每月合计准确，改进个人分摊的累计舍入偏差。仅人力租期发生额使用新规则，原共享票款分配函数及其他六模块不变。

每月先按有效工资名单等份计算，使用大整数有理数保存未分尽的精确金额。分配该月剩余最小单位时，优先补给本自然年累计应摊与已摊差额最大的在场人员；完全相等才按稳定编号决定顺序。每人当月最多承接一个剩余单位，保持当月向下／向上取整两档。跨自然年重置，不给当月不在名单的人分摊，缺名单不猜测。

后续月份不会倒改此前已算月份；查询必须以同年完整来源先计算再筛选，不因只查单人、单月或切换粒度重新分配尾差。混合源精度保留每月自己的精度，累计公平上限为同年已使用的最大舍入单位，不声称未来更高精度可抹去过去舍入。在当前全部精确到分且同样参与月份的六人场景，累计差距不超过一分。
