# 月度财务报表专项验收矩阵

## 验收范围

本矩阵验证“财务区 > 月度财务报表”的菜单与路由、角色边界、六个后端接口、四类自动数据源、四账户公式、字符串金额、期初承接、月结快照、并发版本以及 XLSX（电子表格）下载。

## 验收前置

- 准备 `admin`、`general_manager`、`super_admin`、`chairman`、`boss`、`user` 六类活动账号。
- 准备一个无任何历史月报的首月，一组相邻两月，以及一个上月缺失或未月结的月份。
- 准备已确认主营回款、工资记录、三类已支付报销和已确认资产付款；同时准备草稿、驳回、未支付和已删除反例。
- 准备可导致负数期末的数据、两个并发编辑会话，以及以 `=`、`+`、`-`、`@` 开头的文本。

## 权限与入口

| 编号 | 验收项         | 操作                                                    | 预期结果                                                     |
| ---- | -------------- | ------------------------------------------------------- | ------------------------------------------------------------ |
| P-01 | 管理员菜单     | 使用 `admin` 登录                                       | 财务区显示“月度财务报表”，可进入 `/monthly-financial-report` |
| P-02 | 总经理菜单     | 使用 `general_manager` 登录                             | 显示同一菜单和页面                                           |
| P-03 | 排除其他角色   | 分别使用 `super_admin`、`chairman`、`boss`、`user` 登录 | 菜单不显示；直接访问页面被路由守卫拒绝                       |
| P-04 | 管理员操作     | 打开未月结月份                                          | 可见同步、保存、月结和下载；已月结时可见重新开启             |
| P-05 | 总经理只读     | 打开任意月份                                            | 仅可查看、切换月份和下载；不显示维护、同步、月结或重开操作   |
| P-06 | 前后端双重权限 | 使用无权会话直接调用六个接口                            | 服务端返回 `403`，不产生月报、快照或审计写入                 |

## 六个接口

| 编号 | 方法与路径                                               | 允许角色                   | 验收要点                                                                 |
| ---- | -------------------------------------------------------- | -------------------------- | ------------------------------------------------------------------------ |
| A-01 | `GET /api/monthly-financial-reports/:month`              | `admin`、`general_manager` | 返回月份、状态、版本、四账户、收入、支出、合计、手工项、来源、校验和权限 |
| A-02 | `PUT /api/monthly-financial-reports/:month/manual-items` | `admin`                    | 全量替换手工项，首月可保存期初，版本递增并留审计                         |
| A-03 | `POST /api/monthly-financial-reports/:month/refresh`     | `admin`                    | 重新读取四类业务源，更新自动快照、刷新时间和版本                         |
| A-04 | `POST /api/monthly-financial-reports/:month/close`       | `admin`                    | 再次读取自动源、校验上月和负余额、写入期末及不可变快照                   |
| A-05 | `POST /api/monthly-financial-reports/:month/reopen`      | `admin`                    | 仅已月结可重开，原因必填且不超过 500 字，原快照保留                      |
| A-06 | `GET /api/monthly-financial-reports/:month/export`       | `admin`、`general_manager` | 返回 XLSX（电子表格）附件；持久化月报记录下载审计                        |

## 数据源与归集

| 编号 | 数据源       | 正例                                                   | 反例与预期                                                                                                     |
| ---- | ------------ | ------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------- |
| S-01 | 主营合同回款 | 当月、已确认、未删除的主营根合同回款                   | 草稿、驳回、非主营、已删除或非当月记录不纳入                                                                   |
| S-02 | 主营费率快照 | 为回款保存非默认费率快照                               | 税费、营销预留、商务费用和核算基数按该笔快照计算，不被后续配置反改                                             |
| S-03 | 人力成本     | 当月普通员工工资记录                                   | 超级管理员、董事长、BOSS（经营管理）工资不纳入；结果进一般账户                                                 |
| S-04 | 报销         | 回单实际交易日在当月、已上传付款凭证或已完成的有效报销 | 回单交易日期决定所属月；确认付款时间、管理员上传时间和申请日期不决定归月；基础／大额进一般账户，商务进商务账户 |
| S-05 | 资产付款     | 当月已确认资产根合同付款                               | 非资产、草稿、驳回、已删除或非当月不纳入；结果进一般账户                                                       |
| S-06 | 空月份       | 四类来源均无数据                                       | 来源显示“无记录”及零金额，不伪造数据缺失                                                                       |
| S-07 | 来源明细     | 检查回款、工资、报销和资产付款单笔记录                 | 导出的“自动来源明细”可追溯来源类型、编号、日期、账户、指标、金额和说明                                         |
| S-08 | 人员及月汇总 | 检查工资、基础报销、大额报销和商务报销记录             | 人力成本按员工显示姓名和月份；三类报销按类型显示每人当月合计且无单据细项                                       |
| S-09 | 账户明细折叠 | 首次进入并分别展开四个账户                             | 默认不显示明细；各账户仅在点击展开后显示且可独立收起                                                           |
| S-10 | 银行实际到账 | 主营业务回款 100,000，税费及账户拆分后为 88,280        | 顶部“当月实际到账合计”和下载主表均显示 100,000；88,280 只参与账户结算拆分，不冒充银行到账                      |

## 手工项、金额与公式

| 编号 | 验收项         | 输入／操作                                                           | 预期结果                                                          |
| ---- | -------------- | -------------------------------------------------------------------- | ----------------------------------------------------------------- |
| M-01 | 字符串金额     | 输入 `1`、`1.2`、`1.234567890123`                                    | 接口和页面分别保留 `1`、`1.2`、`1.234567890123`，不默认补两位小数 |
| M-02 | 末尾零标准化   | 输入 `1.2300`                                                        | 保存并回读为 `1.23`，金额数值不变                                 |
| M-03 | 精确十进制合计 | 将 `9007199254740991.123456789012` 与 `0.000000000001` 相加          | 结果为 `9007199254740991.123456789013`，不出现浮点误差            |
| M-04 | 金额边界       | 输入超过 18 位整数、超过 12 位小数、负数、科学计数法或前导零         | 保存拒绝，不静默截断或四舍五入                                    |
| M-05 | 分类绑定       | 伪造手工项的账户或收支方向                                           | 服务端拒绝“账户或收支方向与分类不一致”                            |
| M-06 | 日期边界       | 手工项发生日期不在报表月                                             | 服务端拒绝                                                        |
| M-07 | 其他支出说明   | 一般账户其他支出不填说明                                             | 服务端拒绝                                                        |
| M-08 | 单月数量       | 提交超过 500 条手工项                                                | 服务端拒绝                                                        |
| M-09 | 一般账户公式   | 准备核算基数、利息、人力、基础／大额报销、资产支出、手续费和其他支出 | `期末 = 期初 + 核算基数 + 利息 - 各项支出`                        |
| M-10 | 商务账户公式   | 准备营销预留、商务费用、利息、商务报销和手续费                       | `期末 = 期初 + 营销预留 + 商务费用 + 利息 - 商务报销 - 手续费`    |
| M-11 | 福利账户公式   | 分别准备补充收入与对应福利支出                                       | 两个福利账户独立依“期初＋收入－支出”计算，不串账                  |
| M-12 | 手续费单次扣减 | 对一般与商务手续费分别做有／无对照                                   | 对应账户期末差额恰好等于手续费，不重复扣减                        |
| M-13 | 表格内添加     | 点击某一手工分类汇总行操作列的“添加”                                 | 项目和方向纵向合并；汇总行显示条数与合计，明细行逐条显示本行金额  |

## 期初、月结、快照与并发

| 编号 | 验收项       | 操作                                                   | 预期结果                                                                                          |
| ---- | ------------ | ------------------------------------------------------ | ------------------------------------------------------------------------------------------------- |
| C-01 | 未持久化月份 | 查询全新月份                                           | 返回实时 `draft`（草稿）视图、版本 `0`，不仅因读取创建数据库主表行                                |
| C-02 | 首月初始化   | 管理员填写四账户期初并首次保存                         | 创建版本 `1`，回读与输入一致；总经理无编辑入口                                                    |
| C-03 | 上月承接     | 先月结上月，再打开本月                                 | 本月四账户期初等于上月四账户期末，客户端伪造期初不生效                                            |
| C-04 | 上月阻断     | 存在更早月报，但紧邻上月缺失或未月结                   | 显示 `PREVIOUS_MONTH_NOT_CLOSED`，不允许本月月结                                                  |
| C-05 | 负余额警告   | 构造任一账户负数期末                                   | 生成 `NEGATIVE_*` 警告；未提交 `negativeBalanceConfirmed=true` 时月结拒绝                         |
| C-06 | 月结锁定     | 执行月结后尝试保存或同步                               | 状态为 `closed`（已月结），写操作被拒绝，页面不显示编辑和同步按钮                                 |
| C-07 | 快照完整性   | 月结后检查数据库                                       | 主表保存期末，快照保存报表与内部自动明细，公式版本为 `monthly-finance-v1`                         |
| C-08 | 历史不反改   | 月结后修改合同、工资、报销或资产付款源数据，再查询该月 | 仍返回月结版本快照，历史数值不变                                                                  |
| C-09 | 重新开启     | 填写原因重开已月结历史报表                             | 目标月及其后续已月结月份变为 `reopened`（已重新开启）、版本递增；旧快照和关闭日志保留             |
| C-10 | 重复月结     | 重开后修正并再次月结                                   | 以新版本新增另一份快照，不覆盖旧快照                                                              |
| C-11 | 并发保护     | 两个会话使用相同 `expectedVersion` 先后保存            | 只有首个事务成功；后一个返回 `409` 和 `MONTHLY_FINANCE_VERSION_CONFLICT`                          |
| C-12 | 审计链       | 依次创建、保存、同步、月结、重开、下载                 | 日志分别记录 `create`、`save_manual_items`、`refresh`、`close`、`reopen`、`export` 及操作人和版本 |
| C-13 | 早月补建     | 已存在后续已月结月份时补建更早月份                     | 后续已月结月份保留旧快照并级联进入待重新核算，不能继续沿用旧期初                                  |
| C-14 | 同时点快照   | 月结期间并发改变合同、工资、报销或资产付款             | 月结在单一可串行化事务中读取四类来源和手工项，不混合不同时点数据                                  |
| C-15 | 草稿保护     | 修改期初或手工项后重载、切月、离页、触发版本冲突       | 未明确确认前不丢弃本地草稿；冲突后保留草稿且不被远端响应静默覆盖                                  |

## 下载

| 编号 | 验收项       | 操作                                               | 预期结果                                                                                                 |
| ---- | ------------ | -------------------------------------------------- | -------------------------------------------------------------------------------------------------------- |
| E-01 | 双角色下载   | 管理员和总经理分别下载                             | 均获得 `月度财务报表-YYYY-MM.xlsx`                                                                       |
| E-02 | 工作表完整   | 打开下载文件                                       | 依次包含月度结算、手工项目明细、自动来源明细、校验四个工作表                                             |
| E-03 | 模板与金额   | 检查主表版式、实际到账和账户结算                   | 主表保留五个模板区块、合并单元格和边框；金额为数值单元格，结算公式按人民币分精度显示                     |
| E-04 | 公式注入防护 | 在说明或凭证中保存以 `=`、`+`、`-`、`@` 开头的文本 | 作为内联文本写入且无公式节点，打开时不执行                                                               |
| E-05 | 月结版本下载 | 月结后修改源数据并再下载                           | 导出仍与月结快照一致                                                                                     |
| E-06 | 下载留痕     | 下载已持久化月报                                   | 审计日志记录操作人、角色、报表版本和时间                                                                 |
| E-07 | 人员容量     | 同月存在八名以上报销人员                           | 主表前六名独立显示，其余汇总为“其他 N 人”；自动来源明细仍完整保留所有人员记录                            |
| E-08 | 打印与公式   | 打开主表并检查打印预览和公式                       | A1:H32 为纵向单页打印区；期初、支出、福利及四账户期末公式均可追溯且与系统期末对账                        |
| E-09 | 支出金额展示 | 检查薪资行政、行政人员和商务人员三处               | 薪资行政合并区直接显示计算合计；行政和商务金额行左侧分别显示对应总额，人员列显示各人金额，整行无说明文字 |
