# 开票申请专项验收矩阵

> 更新日期：2026-08-20  
> 验收原则：开票申请表示向客户开具发票，三联单的“本次付款”是客户拟支付金额，绝不作为我公司对外付款。

## 五、材料路由契约

| 路由                                                               | 用途             | 主营三联单                                                                                | 权限要求                                         |
| ------------------------------------------------------------------ | ---------------- | ----------------------------------------------------------------------------------------- | ------------------------------------------------ |
| `GET /api/invoice-applications/:id/materials/:materialId/preview`  | 业务页预览       | 只返回“其他费用”派生预览，不泄漏其他工作表                                                | 申请人、本轮总经理或管理员组                     |
| `GET /api/invoice-applications/:id/materials/:materialId/download` | 完整原件审计下载 | 返回未修改的完整 Excel（电子表格）原件                                                    | 同上，并执行受控路径与摘要校验                   |
| `GET /api/invoice-applications/:id/materials/:materialId/print`    | 管理员盖章打印   | 优先返回只显示“其他费用”的 PDF（便携式文档格式），安全回退时返回单工作表 XLSX（电子表格） | 仅管理员组且材料 `requiresSeal=true`（需要盖章） |
| `GET /api/invoice-applications/:id/application-preview`            | 申请单预览       | 提交后为申请人单签版，总经理通过后为同页双签版                                            | 申请人、本轮总经理或管理员组                     |
| `POST /api/invoice-applications/triplicate-inspection`             | 上传前金额检查   | 返回“其他费用－本次付款”整数分、表头／合计单元格和明细范围，不保存临时文件                | 仅普通员工及符合资格的主营主合同                 |

普通原件下载、业务预览和管理员打印不共用模糊查询参数；前端管理员的主操作固定使用 `/print`（打印）语义端点。
