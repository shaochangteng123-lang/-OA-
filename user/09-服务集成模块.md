# 09 - 服务集成模块

## 模块概述

服务集成模块负责与外部第三方服务的集成，主要包括飞书（Feishu/Lark）OAuth 认证和 API 调用，以及 Notion 集成（如适用）。

## 主要功能

### 1. 飞书集成
- OAuth 2.0 登录
- 用户信息获取
- Access Token 管理
- API 调用封装

### 2. Notion 集成（可选）
- Notion API 集成
- 数据同步
- 内容导入导出

### 3. Token 管理
- Access Token 获取
- Token 刷新
- Token 缓存

### 4. API 封装
- 统一的 API 调用接口
- 错误处理
- 重试机制

### 5. 节假日通知集成
- 自动搜索中国政府网政策库中的国务院办公厅年度节假日通知
- 抓取通知正文并解析放假日、调休上班日
- 将结果写入 `holidays` 表供日历、日志、请假和周报任务统一使用

### 6. 本地发票 OCR（文字识别）

- 使用 `pdftohtml` 提取电子发票文字坐标
- 坐标提取时忽略 PDF（便携式文档格式）内嵌图片，避免在上传临时目录生成无业务引用的旁生图片
- 无文字层时回退到图片 OCR（文字识别）流程

### 7. 入职邀请函工资识别

- [server/services/invitationSalaryOcr.ts](../server/services/invitationSalaryOcr.ts) 只处理正式入职邀请函第一页，第二页重复内容不参与识别
- 优先通过 `pdftotext` 读取文字层；无法识别时使用 `pdftoppm` 只转换第一页，再调用本地 PaddleOCR（飞桨文字识别）
- 优先匹配“原则每月发放”，并兼容“月度税前工资”“每月税前工资”“月保障薪酬”等表述
- 同时识别出年工资时校验其是否等于月工资乘以 12，防止误把固定部分或浮动部分当作完整月工资
- 识别失败返回业务结果，不阻止正式入职邀请函文件归档；识别过程不在日志中输出工资原文

### 8. 人事档案类型识别

- [server/services/employeeDocumentClassifier.ts](../server/services/employeeDocumentClassifier.ts) 逐页识别十种固定人事档案首页，并识别离职证明、职业资格材料及通用资料标题等“其他”页段边界
- [server/services/employeeDocumentBundle.ts](../server/services/employeeDocumentBundle.ts) 按首页边界归组连续页面，并将每种类型拆成独立文件
- 每页优先读取 PDF（便携式文档格式）文字层；扫描件只转换当前页，再调用本地 PaddleOCR（飞桨文字识别）
- 正式标题用于识别新页段，身份证、银行卡和横向学历证书使用组合特征判断，避免旋转扫描导致标题顺序错乱，也避免材料正文提到其他文件名时错误切段
- 类型顺序不固定；缺失类型不生成记录，同一类后续无标题页面沿用当前类型，遇到其他资料标题后切换到“其他”
- 单独上传且完全无法匹配固定十类的有效文件整份归入“其他”；“附件”开头的合同内嵌标题不会被误拆成其他资料
- 同一整册出现多份额外材料时按各自边界分别拆分，数据库类型统一为“其他”，展示文件名保留识别到的资料名称
- 图片识别和拆分临时文件在处理后清理；分类过程不记录档案正文，避免身份证、银行卡和合同内容进入服务器日志

### 9. 劳动合同期限与工资同步

- [server/services/employmentContractOcr.ts](../server/services/employmentContractOcr.ts) 优先读取劳动合同前四页文字层，扫描件按第二页、第一页、第三页、第四页顺序执行 OCR（文字识别）
- 在“劳动合同期限”条款内提取起止日期；同时存在试用期时选择跨度最长的正式合同期限，并兼容扫描日期中的下划线及常见误识别
- [server/services/payrollRecordSync.ts](../server/services/payrollRecordSync.ts) 统一同步当前及未来月份工资；涨薪起算日优先使用最早一份已识别合同的开始日期，没有合同数据时才回退入职日期
- 正式邀请函上传会重置本月工资手工标记；合同新增、删除触发的自动重算保留管理员手工工资、缴费基数和个税

### 10. 入职模板员工编号写入

- [server/services/onboardingTemplateNumber.ts](../server/services/onboardingTemplateNumber.ts) 使用 `pdftohtml（PDF 文字坐标提取工具）` 逐页读取文字、坐标和字体颜色，再使用 `pdf-lib（PDF 处理库）` 写入当前员工编号
- 入职邀请函处理全部页面；劳动合同书第 1 页处理右上角黑色编号，第 2 页起处理左上角蓝色“合同编号”；新员工入职申请表只处理第 1 页
- 三类模板上传时逐页试写示例编号；缺少任一目标页编号、文件加密或页面旋转异常时直接拒绝保存
- 自动写入编号只用于员工下载入职模板；管理员上传至 `employee_documents` 的历史或正式人事档案不调用本服务
- 管理员预览模板时返回原模板，员工下载时生成带当前编号的临时副本；原模板和管理员上传的人事档案内容、编号及文件名均不改写
- 员工编号由 ASCII（美国信息交换标准代码）字符组成，使用内置无衬线字体写入，不需要加载中文字体

### OAuth 登录流程

#### 1. 获取登录 URL
```typescript
// server/services/feishu.ts
export const getFeishuLoginUrl = () => {
  const params = new URLSearchParams({
    app_id: process.env.FEISHU_APP_ID!,
    redirect_uri: process.env.FEISHU_REDIRECT_URI!,
    state: generateRandomState() // 防 CSRF
  })

  return `https://open.feishu.cn/open-apis/authen/v1/index?${params}`
}
```

#### 2. 处理回调
```typescript
export const handleFeishuCallback = async (code: string) => {
  // 1. 获取 access_token
  const tokenResponse = await fetch(
    'https://open.feishu.cn/open-apis/authen/v1/access_token',
    {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({
        grant_type: 'authorization_code',
        client_id: process.env.FEISHU_APP_ID,
        client_secret: process.env.FEISHU_APP_SECRET,
        code
      })
    }
  )

  const { access_token } = await tokenResponse.json()

  // 2. 获取用户信息
  const userInfo = await getFeishuUserInfo(access_token)

  return userInfo
}
```

#### 3. 获取用户信息
```typescript
export const getFeishuUserInfo = async (accessToken: string) => {
  const response = await fetch(
    'https://open.feishu.cn/open-apis/authen/v1/user_info',
    {
      headers: {
        'Authorization': `Bearer ${accessToken}`
      }
    }
  )

  const data = await response.json()

  return {
    feishu_user_id: data.data.user_id,
    name: data.data.name,
    avatar_url: data.data.avatar_url,
    email: data.data.email
  }
}
```

### 飞书 API 调用

#### Tenant Access Token
```typescript
let cachedTenantToken: {
  token: string
  expires_at: number
} | null = null

export const getTenantAccessToken = async () => {
  // 检查缓存
  if (cachedTenantToken && cachedTenantToken.expires_at > Date.now()) {
    return cachedTenantToken.token
  }

  // 获取新 token
  const response = await fetch(
    'https://open.feishu.cn/open-apis/auth/v3/tenant_access_token/internal',
    {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({
        app_id: process.env.FEISHU_APP_ID,
        app_secret: process.env.FEISHU_APP_SECRET
      })
    }
  )

  const data = await response.json()

  // 缓存 token（提前 5 分钟过期）
  cachedTenantToken = {
    token: data.tenant_access_token,
    expires_at: Date.now() + (data.expire - 300) * 1000
  }

  return cachedTenantToken.token
}
```

#### 调用飞书 API
```typescript
export const callFeishuAPI = async (
  endpoint: string,
  options: RequestInit = {}
) => {
  const token = await getTenantAccessToken()

  const response = await fetch(
    `https://open.feishu.cn/open-apis${endpoint}`,
    {
      ...options,
      headers: {
        'Authorization': `Bearer ${token}`,
        'Content-Type': 'application/json',
        ...options.headers
      }
    }
  )

  if (!response.ok) {
    throw new Error(`飞书 API 调用失败: ${response.statusText}`)
  }

  return response.json()
}
```

## 错误处理

### 飞书 API 错误
```typescript
export class FeishuAPIError extends Error {
  code: number

  constructor(message: string, code: number) {
    super(message)
    this.code = code
    this.name = 'FeishuAPIError'
  }
}

export const handleFeishuError = (error: any) => {
  if (error.code === 99991663) {
    throw new FeishuAPIError('Token 已过期', error.code)
  }

  if (error.code === 99991668) {
    throw new FeishuAPIError('应用权限不足', error.code)
  }

  throw new FeishuAPIError(error.msg || '未知错误', error.code)
}
```

### 重试机制
```typescript
export const retryFeishuAPI = async <T>(
  fn: () => Promise<T>,
  maxRetries = 3
): Promise<T> => {
  let lastError: Error

  for (let i = 0; i < maxRetries; i++) {
    try {
      return await fn()
    } catch (error) {
      lastError = error as Error

      // 如果是 token 过期，清除缓存重试
      if (error instanceof FeishuAPIError && error.code === 99991663) {
        cachedTenantToken = null
      }

      // 等待后重试
      await new Promise(resolve => setTimeout(resolve, 1000 * (i + 1)))
    }
  }

  throw lastError!
}
```

## Webhook 处理

### 飞书事件订阅
```typescript
import crypto from 'crypto'

// 验证飞书事件签名
export const verifyFeishuSignature = (
  timestamp: string,
  nonce: string,
  encryptKey: string,
  body: string,
  signature: string
): boolean => {
  const data = `${timestamp}${nonce}${encryptKey}${body}`
  const hash = crypto
    .createHash('sha256')
    .update(data)
    .digest('hex')

  return hash === signature
}

// 处理飞书事件
export const handleFeishuEvent = async (event: any) => {
  switch (event.type) {
    case 'url_verification':
      // 首次验证
      return { challenge: event.challenge }

    case 'event_callback':
      // 处理具体事件
      await processFeishuCallback(event.event)
      return { success: true }

    default:
      console.warn('未知的飞书事件类型:', event.type)
      return { success: false }
  }
}
```

## 使用示例

### 登录流程
```typescript
// 前端：获取登录 URL
const loginUrl = await api.get('/api/auth/feishu')
window.location.href = loginUrl

// 后端：处理回调
router.get('/api/auth/feishu/callback', async (req, res) => {
  const { code } = req.query

  try {
    const userInfo = await handleFeishuCallback(code as string)

    // 创建或更新用户
    let user = db.prepare(
      'SELECT * FROM users WHERE feishu_user_id = ?'
    ).get(userInfo.feishu_user_id)

    if (!user) {
      const result = db.prepare(`
        INSERT INTO users (name, feishu_user_id, avatar_url, email)
        VALUES (?, ?, ?, ?)
      `).run(
        userInfo.name,
        userInfo.feishu_user_id,
        userInfo.avatar_url,
        userInfo.email
      )

      user = { id: result.lastInsertRowid, ...userInfo, role: 'user' }
    }

    // 保存会话
    req.session.user = user

    res.redirect('/home')
  } catch (error) {
    res.redirect('/login?error=auth_failed')
  }
})
```

## 注意事项

1. **Token 安全**：
   - 不要在前端暴露 App Secret
   - Token 仅在服务端使用
   - 定期轮换密钥

2. **API 限流**：
   - 遵守飞书 API 调用频率限制
   - 实现请求队列
   - 缓存常用数据

3. **错误处理**：
   - 完善的错误日志
   - 友好的错误提示
   - 自动重试机制

4. **权限范围**：
   - 只申请必要的权限
   - 遵循最小权限原则
   - 定期审查权限使用

5. **节假日通知来源**：
   - 默认使用中国政府网政策库搜索接口发现年度通知
   - 如官方页面结构变化，可通过 `HOLIDAY_SOURCE_URL` 临时指定通知链接后执行 `npm run update:holidays 年份`
   - 自动任务只在年份数据缺失时写入，避免每天重复覆盖已有数据
